# MLFluent – Android Application

## Overview
MLFluent is an educational Android application containing 350 questions designed to help learners develop their knowledge of Python libraries commonly used in machine learning.

## Key Features
- 350 questions covering Python machine-learning libraries
- Focus on library functions, syntax and practical usage
- Supports knowledge reinforcement and self-assessment
- Designed for independent learning and revision

## Download
The Android APK is available in this repository. Download the APK file to install the application on an Android device.
